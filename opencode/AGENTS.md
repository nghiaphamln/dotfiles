# OpenCode Global Instructions

Use these instructions unless a project-local `AGENTS.md` or `CLAUDE.md` adds more specific constraints.

## Skill Routing

- Load `karpathy-guidelines` for non-trivial implementation, review, or refactor work.
- Load `systematic-debugging` before fixing bugs, test failures, or unexpected behavior.
- Load `test-driven-development` for applicable app-level behavior changes in repositories with a test runner.
- Load `security-and-secrets` for auth, credentials, permissions, trust boundaries, untrusted input, or explicit security reviews.
- Load `code-review` for code or pull-request reviews.
- Load `git-conventions` before creating branches, staging, committing, or writing commit messages.
